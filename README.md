# Stationery World Uganda

Welcome to **Stationery World Uganda**, a web-based platform designed to showcase and manage stationery products for customers and organizations. This repository contains the full website code, deployment guides, and supporting documentation.

---

## 🛠 Project Features

- Browse and explore stationery products
- Guides for deployment and email setup
- Clear documentation for implementation and testing
- Organized media and resources for easy management

## 🚀 Getting Started (Local Setup)

Follow these steps to run the project locally:

1. **Clone the repository**

```bash
git clone https://github.com/E5m1lebk/Stationery-World-Uganda.git
cd Stationery-World-Uganda
````

2. **Create a virtual environment**

```bash
python -m venv venv
```

3. **Activate the environment**

```bash
# Windows
venv\Scripts\activate
```

4. **Install dependencies**

```bash
pip install -r requirements.txt
```

5. **Run the development server**

```bash
python manage.py runserver
```

6. Open your browser and go to `http://127.0.0.1:8000` to view the website.
